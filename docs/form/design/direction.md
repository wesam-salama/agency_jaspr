STORY: A visitor sees the approach, reads a study, then starts a contextual enquiry. An editor changes a structured record, previews it and publishes into browser-local demo storage.

FIRST VIEWPORT: A wide eye-level courtyard view carries the opening below Form's wordmark and native navigation.
