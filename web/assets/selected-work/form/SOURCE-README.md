# Form Architecture editable source delivery

Self-initiated studio concept. Created 13 October 2026. All architecture studies and business facts are fictional. The generated spatial views are art direction evidence, not built architectural work. Diagrams show relationships, not construction drawings.

Start a local HTTP server at the extracted directory, then open site/index.html. The website and project editor require JavaScript. The editor publishes in the same browser only; no server or account is involved. Contact previews a demo receipt and sends nothing. The enquiry demo stores fictional test details locally; the agency enquiry is a separate email-draft flow.

| Folder | Open it for |
| --- | --- |
| `site/` | Public website, bilingual project data, editor, baseline and focused tests. |
| `source/` | Editable identity SVGs, identity proofs and asset/provenance manifests. |
| `studies/` | Original generated study images, WebP exports and editable concept diagrams. |
| `fonts/` | Bundled fonts and their licences. |
| `records/design/` | Website/editor design decisions and scope. |
| `records/production/` | Generation prompts, export records and delivery scope. |
| `records/presentation-sources/` | Editable case-board HTML and rendered PNGs. |
| `records/verification/` | Historical checks, logs and website/agency screenshots. |
| `records/tools/` | Repository maintenance and verification scripts. |

The standalone website works directly from this extracted layout. Maintenance scripts expect the full agency repository: run them from its root and consult `docs/form/README.md` there. In that repository, `python3 docs/form/tools/package_source.py` rebuilds this archive without rewriting images or provenance. The production and verification records describe actual scope and limitations.

Do not invent an available domain, real practice biography, certifications, construction authorship, commissioned client or commercial results. Independent commercial translation, trademark/domain clearance and physical printing remain unverified.
