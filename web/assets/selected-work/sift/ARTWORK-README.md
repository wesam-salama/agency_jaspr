# Sift Coffee artwork

Self-initiated brand strategy and identity by Creative Media, 2026. This package contains authored concept artwork and a brand guide.

Open `assets/selected-work/sift/sift-brand-guide.pdf` for the portable guide. The companion HTML keeps the project's original relative asset hierarchy; extract the entire archive before opening it.

The `source/` directory contains forty editable SVG masters. Logos use outlined vectors; other text remains editable and the SVGs embed their licensed fonts. `product-canon.json` contains the exact sample coffee records. `asset-manifest.json` identifies each file and its dimensions. Preserve `source/fonts/` and the font licence notices when redistributing or editing.

Application families: 250 g collection, 1 kg format, shipping carton/tape, brewing cards, sample box/insert, wholesale sheet, social templates and counter display.

The longer middle rule is Cobalt on light surfaces. Monochrome/reversed versions retain the distinctive line length. Roast Orange is an identifier/decorative surface; use Ink on Paper for ordinary text. English and Arabic have independent reading direction and spacing.

SVG dimensions describe digital artboards, not supplier-approved dielines. Before physical production, obtain the substrate/print specification, required market information and independent copy review. Coffee origin, tasting notes and recipes are fictional content fixtures. Mockup images are generated concept presentations.
