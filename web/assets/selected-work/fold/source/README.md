# Fold editable identity source

All files are authored studio-concept artwork, dated 15 October 2026.

- `build-identity.py`: deterministic source for the manually drawn FOLD/F paths, clear-space and small-size proof, four front/back garment diagrams plus their composite, packaging layouts and editable guide/boards. Run with Python 3. It reads the licensed local WOFF2 files, embeds them in SVGs containing text and never changes product photography.
- `identity-board.html`, `packaging-board.html`: editable 2000 × 1500 presentation compositions using `identity.css`. They describe designed digital work; they are not screenshots of the store.
- `fold-brand-guide.html`: editable responsive guide with A4 print styles and local fonts. Open in a browser; Print exports its six-section guide. Preserve background graphics when printing.
- `fl01-construction.svg` through `fl04-construction.svg`, `garment-construction.svg`: explanatory technical geometry for locked front/back feature counts. Not to scale; not manufacturing patterns.
- `identity-manifest.json`: vector identity/packaging inventory and checksums.
- `font-manifest.json`: official source URLs, licence records and file checksums.

The adjacent `identity/` contains ink, ivory, black and white wordmarks/monograms plus `fold-clear-space.svg`. The adjacent `packaging/` contains editable hangtag front/back, bilingual illustrative care label and single mailer face.

The marks are manually authored closed paths. The F terminal has one controlled cut/displacement. Do not redraw with a font or an image-generation model. Text in the packaging and diagrams remains editable SVG text, with exact fonts embedded for portable rendering; font licences travel in the adjacent `fonts/` folder.

The repository's `docs/fold/verification/identity/` contains actual Chrome captures, provenance sidecars and guide overflow/image/font checks at 390 and 1440 px. `docs/fold/verification/font-checks.json` records pure-Python SFNT name/cmap/axis checks and WOFF2 container validation. These checks concern artwork, fonts and guide rendering; the separate store verification establishes shopping behavior.

No production die line, label legal compliance, physical material specification, certification, supplier approval or manufactured sample is claimed. Garment composition, stock, care and price are fictional fixtures for a self-initiated studio project.
